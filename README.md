
# QuickNotes

QuickNotes is a note-taking web app built with HTML, CSS and JavaScript. You can add short notes in different categories, search through them, and delete the ones you no longer need. Your notes are saved in the browser, so they are still there after you refresh the page.

## Features

- Add notes with a category (Personal, Work or Study)
- Validation for empty notes and notes over 200 characters
- Delete individual notes
- Search notes as you type (not case-sensitive)
- Note count that updates for zero, one and many notes
- Notes saved with localStorage
- Responsive layout for small screens
- "Clear all" button with a confirmation step (bonus)

## How to run locally

1. Clone the repository: `git clone https://github.com/keishaochieng/quicknotes-app`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server** (or double-click `index.html` to open it in a browser).
